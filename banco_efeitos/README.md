# 🔊 Banco de Efeitos Sonoros

Pasta para os seus efeitos sonoros **grátis** (whoosh, ding, suspense, aplausos...).

O roteiro gerado pela IA sugere um efeito para cada cena
(campo `efeito_sonoro_sugerido`) — é aqui que você guarda os `.mp3`/`.wav`
de cada um, para a **Fase 6** juntar tudo no vídeo final.

Sugestão de fontes gratuitas:
- freesound.org
- pixabay.com/pt/sound-effects
- youtube áudio livre (estúdios de efeitos)
