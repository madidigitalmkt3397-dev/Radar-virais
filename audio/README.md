# 🎙️ Áudios de narração (Fase 4)

Gerados automaticamente pelo `gerar_narracao.py` — **um `.mp3` por cena**
(`cena1.mp3`, `cena2.mp3`...), alinhados com os números do `roteiro.json`
e com os arquivos da pasta `cenas/`.

- Mudou o roteiro? Rode `python gerar_narracao.py` de novo (tudo é regerado)
- Quer trocar a voz? Edite `VOZ` no `gerar_narracao.py`
- O render (`render_video.py`) pega esses audios sozinho
